# Exegora

Exegora is a full-stack Scripture study platform built to help users explore the Bible through original-language analysis, historical context, translation comparison, and transparent source attribution.

## Tech Stack

- Frontend: React + TypeScript (planned)
- Backend: Spring Boot (Java) (planned)
- Database: PostgreSQL (planned)

## Status

🚧 Currently in development.

Following a structured learning roadmap while building the application from scratch.
